# Build guide: Sovereign ESG Tracker in Power BI Desktop

You need Power BI Desktop (free, Windows; install it from the Microsoft Store).

There are two ways to get the report.

## Fast path: open the generated project

[`project/ESG Tracker.pbip`](project) is a complete Power BI project: the model, all 29 measures, the relationships, the theme and four report pages. It is generated by `make_pbip.py`.

1. Clone or download this repository.
2. Double-click `powerbi/project/ESG Tracker.pbip`. If Power BI says the project format is a preview feature, turn on **File > Options and settings > Options > Preview features > Power BI Project (.pbip) save option** and, if listed, **Store reports using enhanced metadata format (PBIR)**, then restart and open it again.
3. Click **Refresh**. The six tables load from this repository on GitHub. When asked how to connect, choose **Anonymous**; if asked about privacy levels, choose **Public**.
4. Check a few cards against [`expected_values.md`](expected_values.md).
5. **File > Save as** `esg_tracker.pbix` in the repository root.

The project files were produced by a script and validated against Microsoft's published file schemas, but schema-valid is not the same as rendering as intended. If a visual shows an error or looks wrong, fix it in Power BI using the page tables in section 7 below, or rebuild that one visual by hand.

To load the data from your own disk instead of GitHub, open **Transform data**, select the `DataSource` parameter and replace the URL with the path form of your local `data/model/` folder, then change `Web.Contents` to `File.Contents` in each query.

## Manual path: build it from scratch

Use this if the project will not open, or if you want to learn the build. Time: about 1 to 2 hours. A picture of each finished page is in [`../mockups`](../mockups). The mockups were drawn from the same data, so your pages should show the same numbers.

---

## 1. Load the six tables

1. **Home > Get data > Text/CSV**. Open `data/model/dim_country.csv`, then click **Transform Data** (not Load).
2. In Power Query, repeat for the other five files with **New Source > Text/CSV**.
3. Rename the queries (right-click > Rename):

   | File | Rename to |
   |---|---|
   | dim_country | `Country` |
   | dim_indicator | `Indicator` |
   | dim_year | `Years` |
   | fact_observations | `Observations` |
   | fact_scores | `Scores` |
   | fact_latest | `Latest` |

4. Check the data types (the icon left of each column name):

   | Column | Type |
   |---|---|
   | every `year`, `reported_year`, `latest_year`, `years_since_update`, `rank_in_year`, `indicators_used`, `indicators_possible`, `is_carried_forward` | Whole number |
   | `value`, `latest_value`, `score` | Decimal number |
   | `in_score` | True/False |
   | everything else | Text |

5. **Close & Apply**.

## 2. Relationships

Open **Model view** (left edge, third icon). Power BI will have guessed some of these. Make sure exactly these seven exist, each **many-to-one, single direction**, from the fact to the dimension. Delete any others.

| From (many) | To (one) |
|---|---|
| `Observations[iso3]` | `Country[iso3]` |
| `Observations[indicator_id]` | `Indicator[indicator_id]` |
| `Observations[year]` | `Years[year]` |
| `Scores[iso3]` | `Country[iso3]` |
| `Scores[year]` | `Years[year]` |
| `Latest[iso3]` | `Country[iso3]` |
| `Latest[indicator_id]` | `Indicator[indicator_id]` |

`Latest` is deliberately not connected to `Years`: it holds each series' newest value, whatever the year slicer says.

## 3. Tidy the model

- Select `Years[year]`, then **Column tools > Summarization > Don't summarize**. Do the same for every other year, rank and count column.
- Select `Country[country]`, then **Column tools > Data category > Country/Region**. The map needs this.
- In **Model view**, hide the key columns in the fact tables (`iso3`, `indicator_id`, `year` in Observations, Scores and Latest) so that visuals always use the dimension columns. Right-click > **Hide in report view**.

## 4. Measures

1. **Home > Enter data**, name the table `Measures`, click Load. This gives the measures one home.
2. Open [`measures.dax`](measures.dax). For each measure: select the `Measures` table, **Modeling > New measure**, paste from the measure's name to the end of its formula, press Enter, then set the format given in the comment above it (**Measure tools > Format**).
3. When they are all in, delete the placeholder `Column1` from `Measures`.

There are 29 measures. Do section 1 and 2 first and check them (next step) before adding the rest.

## 5. Check against the expected values

Put a few **Card** visuals on a blank page and compare with [`expected_values.md`](expected_values.md):

- `Country Count` should be **193**
- `Coverage %` should be **60.6%**
- `ESG Score` should be **49.7**

Add a slicer on `Country[country]`, pick United States, and `ESG Score` should become **62.8** and `ESG Rank Label` **31 of 181**. If these match, the model and measures are right. If not, the usual causes are a missing relationship, a `year` column typed as text, or a measure pasted with part of the next one.

## 6. Theme

**View > Themes (dropdown arrow) > Browse for themes**, choose [`theme.json`](theme.json).

Set the page background: click empty canvas, **Format > Canvas background**, colour `#F9F9F7`, transparency 0%.

## 7. The pages

Give every page the same header: a text box top-left for the title, and the slicers along the top right. Turn on **Title** for each visual and use the names below.

### Page 1: Overview

| Visual | Fields |
|---|---|
| Slicer (dropdown) | `Years[year]`. Set to **Between**, so the last year selected is the one shown |
| Slicer (dropdown) | `Country[region]` |
| 5 Cards | `Country Count`, `Indicator Count`, `Reported Values`, `Coverage %`, `ESG Score` |
| Filled map | Location `Country[country]`, Tooltips `ESG Score`. Then **Format > Fill colors > fx**: format style Gradient, based on `ESG Score`, lowest `#F0EFEC`, highest `#256ABF` |
| Clustered bar chart, "Top 10 countries" | Y-axis `Country[country]`, X-axis `ESG Score`. In the Filters pane, set `country` to **Top N**, 10, by `ESG Score`. Data labels on |
| Line chart, "Average ESG score by region" | X-axis `Years[year]`, Y-axis `ESG Score`, Legend `Country[region]` |

Card title for the page: use the `Overview Title` measure (text box > insert value, or a Card).

Map note: if the map is disabled, enable it under **File > Options and settings > Options > Security > Map and filled map visuals**. A few World Bank country names (for example "Korea, Rep.") may not be recognised by the map. Those countries still appear in every other visual.

### Page 2: Country profile

| Visual | Fields |
|---|---|
| Slicer (dropdown, single select) | `Country[country]` |
| Slicer | `Years[year]`, Between |
| Card, as the page title | `Profile Title` |
| 6 Cards | `ESG Score`, `ESG Rank Label`, `Environment Score`, `Social Score`, `Governance Score`, `ESG Score 5Y Change` |
| 2 Cards, "against peers" | `Region ESG Score`, `ESG vs Region` |
| Line chart, "Pillar scores over time" | X-axis `Years[year]`, Y-axis `Pillar Score`, Legend `Scores[pillar]`. Fix the Y-axis range to 0 to 100 |
| Table, "Indicators" | `Indicator[pillar]`, `Indicator[indicator]`, `Indicator Value`, `Value Reported In`, `Indicator Score`. Filter `Indicator[in_score]` is True. Sort by `Indicator Score` descending. On `Indicator Score`: **Cell elements > Data bars** on |

For the line chart to ignore the year slicer and always show the full history, select the year slicer, **Format > Edit interactions**, and set the line chart to **None**.

### Page 3: Compare

| Visual | Fields |
|---|---|
| Slicer | `Years[year]`, Between |
| Scatter chart, "Governance against social outcomes" | X-axis `Governance Score`, Y-axis `Social Score`, Values `Country[country]`, Legend `Country[region]`. Fix both axes to 0 to 100 |
| Matrix, "Average score by region and pillar" | Rows `Country[region]`, Columns `Scores[pillar]`, Values `Pillar Score`. **Cell elements > Background color > fx**, gradient `#F0EFEC` to `#256ABF`. Turn off row and column subtotals |
| Clustered bar chart, "Biggest 5-year gains" | Y-axis `Country[country]`, X-axis `ESG Score 5Y Change`. Filter `country` Top N, 10, by `ESG Score 5Y Change` |

### Page 4: Data gaps

This page is about the data itself: what is reported, by whom, and how old it is.

| Visual | Fields |
|---|---|
| 5 Cards | `Coverage %`, `Carried Forward %`, `Stale Series %`, `Series Never Reported`, `Avg Years Since Update` |
| Matrix, "Coverage by theme and year" | Rows `Indicator[pillar]` then `Indicator[theme]`, Columns `Years[year]`, Values `Coverage %`. Background color gradient as above. Expand rows to the theme level |
| Clustered bar chart, "Least current indicators" | Y-axis `Indicator[indicator]`, X-axis `Avg Years Since Update`. Top N 10 by `Avg Years Since Update` |
| Clustered bar chart, "Countries with least data" | Y-axis `Country[country]`, X-axis `Coverage %`. Top N 10, **Bottom**, by `Coverage %` |

Check: in the matrix, Governance > "Government effectiveness" for 2019 should read **99.0%**, and Environment > "Energy use & security" for 2019 should read **0.1%** (most of those series stop in 2015).

## 8. Finish

1. Rename the pages, delete your test page, and save as `esg_tracker.pbix` in the repository root.
2. Take a screenshot of each page (**File > Export > Export to PDF**, or Windows Snipping Tool) and save them in `screenshots/`.
3. In `README.md`, replace the mockup images with your screenshots and delete the "Status" note at the top.
4. Optional: **Publish** to the Power BI service and add the link to the README.

## Common problems

| Symptom | Cause |
|---|---|
| A score card shows a number near 50 for a single country | The slicer is on a fact column. Use `Country[country]`, not `Scores[iso3]` |
| `ESG Rank Label` is blank | More than one country is selected |
| `Indicator Value` is blank | More than one indicator is in context. It only shows for a single indicator |
| Coverage is above 100% or tiny | A relationship is missing or runs both ways |
| Totals differ from `expected_values.md` | A `year` column was loaded as text, or a region filter is still applied |
